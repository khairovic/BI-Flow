The architecture we built

Independent services that talk only through the orchestrator
Orchestrator (LangGraph): runs the steps, retries, resumes, writes the run record
Auditor: lineage graph, trace report, "Explain this KPI"
one Docker container per module HTTP + JSON contracts data passed by reference
